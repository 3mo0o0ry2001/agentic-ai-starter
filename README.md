# Agentic AI Starter Kit 🤖

A modular AI Agent built with Python and `aisuite` that can use tools to perform actions like checking weather and file operations.

## Features
- **Tool Calling:** Automatically selects the right tool for the job.
- **Modular Design:** Easy to add new Python functions as tools.

## Setup
1. Clone the repo
2. `pip install -r requirements.txt`
3. Add your API key in `.env`
4. Run `python main.py`
