## 📖 Overview

This project is an advanced **Agentic Workflow** where the LLM doesn't just "chat"—it executes. Built on top of `aisuite`, this agent is equipped with a custom-built **Hallucination Trap** that forces the model to use tools natively, even when it tries to be "lazy."

The agent can browse the live web via Tavily, process information, and autonomously store findings in external files (e.g., `results.txt`).

## ✨ Pro Features

* **🕵️ Hallucination & Laziness Control:** A specialized Regex-based "trap" system that intercepts text-based tool calls and forces technical execution.
* **🌐 Reliable Web Intelligence:** Integrated with **Tavily API** for high-quality, AI-optimized search results without bot-blocking issues.
* **💾 Automatic External Storage:** The agent is hard-coded to prioritize saving data to the file system over just chatting.
* **🔄 Autonomous Loop:** Uses a recursive reasoning loop that allows the agent to chain multiple actions (Search -> Summarize -> Write) in a single request.
* **🔌 Provider Agnostic:** Seamlessly switch between GPT-4o, Claude, or any OpenRouter model.
