## 📖 Overview

This project is not just a standard chatbot wrapper. It implements a robust **Agentic Workflow** using `aisuite`, where the LLM acts as an autonomous orchestrator. 

The core innovation here is the **Hallucination Trap**—a specialized logic layer that intercepts text-based tool calls (model laziness) and forces native execution to ensure the task is actually performed, not just talked about.

---

## ✨ Key Technical Features

* **🧠 Intelligent Orchestration:** Decides the best tool to use (Search, Write, or Weather) based on live user context.
* **🕵️ Hallucination & Laziness Control:** Intercepts instances where the LLM tries to "fake" an action by typing the function name, forcing a technical **Native Tool Call** instead.
* **🌐 Reliable Web Intelligence:** Integrated with the **Tavily API** for high-quality, AI-optimized web search that bypasses common bot-blocking issues.
* **💾 Automatic Persistence:** Hard-coded to prioritize external storage; findings are automatically saved to files like `results.txt` for immediate use.
* **🔄 Chained Reasoning:** Capable of multi-step execution (e.g., Search news -> Summarize findings -> Save to file) in a single autonomous loop.

Execute the main script and interact with your autonomous agent:
